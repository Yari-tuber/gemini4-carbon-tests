- 测试条件：Google Antigravity · Gemini 4 Carbon · High 档 · Turbo 模式
- 会话标题（Antigravity 自动起的）：全息镭射卡牌开包器

## 第 1 轮

模型这一轮干了：48m

````text
请用单个完整的 HTML 文件，制作一个视觉效果惊艳的「全息镭射集换式卡牌（TCG）开包与 3D 检视器」。

核心要求：
1. 开包仪式：初始界面展示一个带有金属光泽的神秘卡包，支持鼠标横向划开（或点击撕开）卡包封口，伴随粒子爆裂光效飞出 3 张不同稀有度的奇幻主题卡牌（R 银闪、SR 碎钻闪、SSR 彩虹全息金闪），卡牌插画请用精细的多层 SVG / Canvas 生成艺术绘制，构图饱满华丽。
2. 殿堂级全息镭射光效（核心考察点）：
   - 当鼠标在任意卡牌上移动时，卡牌需根据鼠标相对坐标产生平滑的带阻尼 CSS 3D 透视倾斜（Perspective Tilt）。
   - 严禁只做简单旋转！必须利用多层渐变、噪点纹理与 CSS 混合模式（mix-blend-mode），实现跟随光照角度实时流转的【彩虹全息衍射反光（Holographic Foil）】、【斜向高光扫光】以及卡面前景与背景之间的【多层 3D 视差景深感】。
3. 交互检视：点击单张卡牌可放大居中进入“鉴赏模式”，支持 360 度翻转查看精美的卡背纹章，并提供滑块手动调节镭射强度与环境光色温。
````
