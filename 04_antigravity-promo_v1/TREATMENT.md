## 1. 三个候选结构与最终选择 (Three Candidate Structures)

### 候选方案 A ——「高度计垂直升空 · 从 9.8G 地面到 0.0G 轨道」（最终选用）
全片以一套贯穿始终的**垂直海拔高度轴（`ALT 000m` → `ALT 900m · ORBIT`）**与物理常数首尾呼应来组织叙事：
- 开场不出现常规光标，而是直接以冷灰巨型数字 **`9.8`**（`m/s² · 工程引力`）砸开纯黑银幕，沉重的代码块与配置卡在背景中垂直坠落砸向底栏地面（`ALT 000m`），不断堆积直至阻塞红槽逼近极限；
- 第 11.00 s 全场硬冻结、全轨数字零静音 1.25 秒，镜头推入静止碎片的缝隙，地面亮起一枚 `#8B7CFF` 双折反重力棱镜核心，展开意图控制台并触发一道**自下而上扫掠的地平线光幕（Rising Light-Horizon）**；
- 摄影机随之沿垂直纵轴持续向上摇升（Vertical Crane Ascent），16 枚模块脱离地面轻盈升空，沿四条纵向流光轨道汇入「感知 · 规划 · 编码 · 验证」四座悬浮立柱，并在重拍上瞬间吸附为 4×4 零重力矩阵；
- 经 2.5D 条带透视工作台柔光展示后，镜头对数潜入状态徽标，在近静音呼吸后翻滚锁定发光紫罗兰巨字 **`0.0 G`**（与开场 `9.8` 形成强烈视觉回响）；
- 结尾拉回辽阔的全景轨道舞台：8 枚半透明工作台模块环绕中央悬浮的「反重力 · ANTIGRAVITY」徽标静默运转，诠释「当工程摆脱引力，思想自由升空」。

### 候选方案 B ——「左右双屏竞速 · 旧工作流 vs 反重力」
左半屏展示传统手动切屏与排错，红标堆积；右半屏由反重力智能体数秒内完成交付并静置留白。直观清晰，但双屏分割削弱了单画幅的呼吸感、留白气场与升空仪式感。

### 候选方案 C ——「发布倒计时清单 · 从 T-5 到 Shipped」
以五项上线检查清单逐项倒数推进，每完成一项点亮一格 UI，最后停在已发布状态。节奏紧凑，但偏通用研发工具套路，未能把「反重力」独有的失重升空意象发挥到极致。

### 选择理由与去同质化核验
选用 **方案 A**。对照样片结构后，本片在**结构（高度轴四重升空 vs 桌面整理）、开场（满屏物理常数 `9.8` 与下坠实景 vs 5 倍特写光标打字）、标志性镜头（自下而上光幕与纵向四柱升空矩阵 vs 径向圆环横向归类）、运镜路径（地面锁死→微倾过载→冻结推近→垂直摇升→2.5D 侧转→对数潜入→全景轨道环绕）、配乐形态（从低音区 `F#2` 沉重落体逐八度向上攀升至 `F#6` 空灵泛音 vs 双马林巴相位漂移与减法抽离）、结尾（全景轨道集群静默运行围绕主视觉 vs 特写光标闪烁熄灭）**六个维度上全部独立原创（6/6 完全不同）。

## 6. 音乐网格与提示点表 (Cue Map · 120 BPM · F# Minor → F# Maj9 / Db Lydian)

- **速度与拍号**：120 BPM，4/4 拍（`1 拍 = 0.500 s = 12 帧`，共 90 拍 = `45.000 s`）。
- **音色编制（VCSL CC0 采样 + NumPy 纯净低频合成）**：
  - `marimba`（木质律动骨架）、`vibraphone`（柔槌和声核心）、`vibraphone_bowed`（失重空间空灵长音）、`glockenspiel`（高空星尘确认音）、`hand_chimes`（柔和钟鸣泛音）、`shaker`（升空段极轻推进脉搏）、温暖二次谐波正弦低音（`F#2 / B2 / C#3 / D#3`）。
- **音高高度映射过程（Pitch-Altitude Process）**：
  1. **S1–S2 地面重压 (`0.00–11.00 s`)**：音域被压制在低音区（`F#2–C#3`），随卡片下坠触发微离调短促木槌与沉闷落体低音，节奏由四分分裂至十六分。
  2. **S3 冻结与点火 (`11.00–16.50 s`)**：`11.00–12.25 s` 全轨数字零休止；`12.25 s` 单颗居中 `vibraphone` F#4 + `hand_chimes` C#5 破冰；`14.50 s` 按键落入温暖 `F#2` 正弦下潜与上行五度分解和弦。
  3. **S4 垂直升空与吸附 (`16.50–25.00 s`)**：音域随镜头高度每两小节向上攀升一个八度（`Octave 3 → Octave 4 → Octave 5`），双声部马林巴与颤音琴交织上行琶音；**`21.50 s`（Beat 43）** 全编制齐奏璀璨 `F# Maj9`（`F#3-C#4-F#4-G#4-A#4-F#5`）锁定 4×4 矩阵！
  4. **S5 扫光展示 (`25.00–31.00 s`)**：`vibraphone_bowed` 长音提前 `0.35 s`（J-cut）涌入，托起通透 Lydian 泛音层。
  5. **S6 巨字 `0.0 G` (`31.00–36.50 s`)**：`31.00–31.75 s` 抽空配乐留白，三声清脆 `glockenspiel`（`C#6 → F#6 → G#6`）锁定 `0.0 G` 并延展温暖低音托底（L-cut 跨入 S7）。
  6. **S7 轨道终章 (`36.50–45.00 s`)**：轻柔稀疏的高音区颤音琴五度呼吸与 `vibraphone_bowed` 长音渐隐于 `45.00 s`。

## 8. 字幕与字体设计 (Subtitle & Title Design)

- **自托管开源字体（OFL，位于 `fonts/`）**：
  - `Inter`（400 / 500 / 600）、`Inter Tight`（600，巨型数字 `9.8` 与 `0.0 G`）、`JetBrains Mono`（400 / 500，高度标尺、文件名与全大写副标）、`Noto Sans SC`（400 / 500 / 700 子集化，中文 UI、主标题与胶囊字幕）。
- **字幕胶囊（Toast）与安全区规则**：
  - 底部居中暗色胶囊（`y = 956 px`），配 `#8B7CFF` 发光说话圆点；所有每句保持时长均 `≥ max(1.8 s, 语音时长 + 0.65 s)`。
  - S1（`9.8`）与 S6（`0.0 G`）巨型数字画面绝不叠加底部字幕；S3 意图台输入文案不重复烧录底部字幕，但完整收录进外挂 `.srt`；所有主体面板均位于 `y ≤ 845 px` 安全区。
