# 提示词

下面是发给模型的原话，一字没改（错别字、标点都保留）。

- 测试条件：Google Antigravity · Gemini 4 Carbon · High 档 · Turbo 模式
- 会话标题（Antigravity 自动起的）：Mini Multi-Track Video Editor

## 第 1 轮

模型这一轮干了：1h 13m

````text
请用单个完整的 HTML 文件，开发一个真正可交互运行的网页版「迷你多轨道视频剪辑器（类似剪映 / Premiere 精简版）」。

核心功能要求（严禁只画静态 UI 壳子，所有核心交互必须真实生效）：
1. 专业暗色工作区布局：
   - 左上：内置素材库（用程序化 Canvas 实时生成 3 段不同风格的动态视觉片段素材，如“赛博网格穿梭”、“流体极光”、“复古倒计时”，以及 2 条文字标题模板和 Web Audio 合成音效素材，可点击或拖拽添加到下方轨道）。
   - 右上：实时合成预览监视器（Canvas）+ 播放/暂停、跳至开头、全屏、当前精确时间码（00:00:00:00）显示。
   - 下半部：多轨道非线性编辑时间轴（至少包含：视频轨道 V1、画中画/特效轨 V2、字幕轨道 T1、音频波形轨道 A1）。
2. 真实时间轴微操交互：
   - 顶部带精细时间刻度尺，支持拖动红色播放指针（Playhead）实时逐帧刷预览画面（Scrubbing），点击播放则按真实帧率合成渲染当前时间点覆盖的视频片段、叠加的自定义字幕与动态音频波形。
   - 轨道上的片段块（Clip）支持：左右拖拽移动起始时间（带边缘磁吸对齐提示线）、拖拽片段左右边缘裁剪持续时长（Trim）、选中片段后按 S 键或点击工具栏【分割（Split）】按钮在指针处将片段一分为二、按 Delete 删除片段。
   - 右侧提供属性检查器（Inspector）：选中字幕或视频片段时，可实时调整字号、颜色、不透明度、缩放比例并在预览窗立即生效，同时提供时间轴整体缩放滑块（Zoom In/Out）。
````
